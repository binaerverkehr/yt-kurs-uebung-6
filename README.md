# Python-Kurs – Übung 6 (Module & Turtle)

Übungsprojekt aus meinem Python-Kurs auf YouTube. Der Code zeigt, wie sich Funktionen auf mehrere Module (`geometrie.py`, `gebäude.py`, `natur.py`) aufteilen und in `main.py` zusammenführen lassen.

Beim Start zeichnet `turtle` eine kleine Szene mit Häusern, Bäumen und Blumen.

## Ausführen

```bash
python main.py
```
